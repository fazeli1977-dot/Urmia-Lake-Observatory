# Data Sources Catalog — Urmia Lake Observatory (ULO)

## Open Zero-Key Sources (Primary)
1. **Element84 Earth Search STAC:** Sentinel-2 L2A & Landsat Collection 2 Level-2 (Surface Reflectance).
2. **JRC Global Surface Water:** Long-term 30m water occurrence and seasonality (1984–present).
3. **Open-Meteo Historical / ERA5-Land:** Temperature, precipitation, reference evapotranspiration (ET0), wind, air quality/dust.
4. **CHIRPS v2.0:** Gridded precipitation time series (1981–present).
5. **HydroSHEDS / HydroBASINS / HydroLAKES:** Scientifically delineated basin, sub-basins, and river network.
6. **GBIF API:** Georeferenced biodiversity occurrence records in the Urmia basin.

## Optional Registration Sources (Supported via Offline Import or Free Token)
1. **DAHITI (DGFI-TUM):** Satellite altimetry water surface elevation.
2. **NASA Earthdata (GPM / MODIS / GRACE-FO):** Regional hydrology and aerosol products.
