# Scientific Methods — Urmia Lake Observatory (ULO)

- **Surface Water Mapping:** Multi-index spectral classification (`NDWI`, `MNDWI`, SWIR thresholding) with explicit scene cloud-cover filtering and shallow-brine / wet-salt crust separation notes.
- **Volume Estimation:** Derived strictly from peer-reviewed Elevation-Area-Volume (E-A-V) hypsometric relationships with explicit uncertainty bounds (never presented as direct bathymetric measurement).
- **Trend & Drought Analysis:** Non-parametric Mann-Kendall significance testing, Sen's slope estimator, and Standardized Precipitation Index (SPI).
